# Backup do Caderno Online

O arquivo `caderno-conteudo-backup.json` contém uma cópia completa do conteúdo salvo no caderno no momento da exportação:

- 4 matérias;
- 9 páginas de estudo, com títulos, textos, resumos e blocos formatados;
- 3 provas;
- 0 arquivos anexados.

Os identificadores privados da conta foram removidos. Os identificadores internos de matérias e páginas foram mantidos para preservar os relacionamentos entre os dados.

## Importante

O código-fonte e o backup estão juntos neste pacote, mas os dados em produção continuam armazenados no banco D1 do GPT Sites. Ao publicar o projeto em outro ambiente, configure um banco D1 e importe este JSON para o usuário autenticado.

Como o backup contém suas anotações de estudo, prefira um repositório privado caso não queira tornar o conteúdo público.
